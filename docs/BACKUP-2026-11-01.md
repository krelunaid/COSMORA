# COSMORA source backup — 1 November 2026

This snapshot saves the mobile/web source currently at 1.0.8, native project configuration, privacy/community/account/seller changes, SQL migrations, and the separately deployed Community service under supabase/functions/cosmora-community. The service's last bundled deployment entrypoint is retained for provenance. No fresh deployment or store submission is caused by this backup.

Last observed Android state: 1.0.8 (48) active in production. Last observed Apple state: 1.0.6 available, 1.0.7 (48) awaiting review; 1.0.8 (49) uploaded but not submitted. These are dated observations and require current portal verification for later release work. The photo service and eight JPEG previews are live; actual phone rendering/timing and automatic thumbnail generation on future uploads remain outstanding.

The Software Kreluna backup contains a source export, Git history bundle, iOS/Android signed packages and selected validation reports, with a SHA-256 file manifest. It excludes environment credentials, signing private keys, dependencies, temporary build products and user media. Existing protected credential/signing locations remain required for rebuilding signed releases. Personal-photo originals and the backfill SQL containing image bytes are deliberately outside this source backup.
